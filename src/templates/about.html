两系统定位说明

本项目由两个相互独立、单向引导的系统组成，职责边界如下。

🎯 系统 A：游戏舆情 AI 分析平台（内容站）

  • 定位：对外品牌与 SEO 获客的内容站。
  • 职责：讲清平台能力、行业科普、按关键词承接搜索流量，引导用户进入数据工具。
  • 页面：主题首页 / AI 监测系统 / 负面风险 / 玩家体验 / 热点追踪 / 商业化争议 / 跨平台聚合（7 页，见底部链接）。
  • 数据：不含实时数据，仅展示能力介绍与数据边界说明，不编造内容。
  • 边界：CTA 单向引导到系统 B（登录后使用），不做数据承载。

⚙ 系统 B：Game Analyzer 数据分析工具（数据产品）

  • 定位：实际落地的数据分析工具，需登录使用。
  • 职责：抓取 Steam / TapTap / Google Play 公开评论 → 清洗（去水军）→ LLM 标签 / 聚类 / 向量检索 → 看板 / 报告 / 预警。
  • 页面：首页落地 / 分析向导 / 数据看板 / 竞品对比 / 复盘归档 / 热点深析 / 订阅。
  • 数据：真实公开数据；经营类指标（收入/留存/漏斗）需接入业务数据，不可验证的功能已下线。
两者关系：系统 A 负责「讲清能力、引入用户」，系统 B 负责「落地分析、产出数据」； 用户路径为 搜索/内容 → 能力认知（A）→ 登录体验（B）→ 看板/报告（B），互不混用。
数据边界口径：评论抓取、情感/主题聚类、负面预警、热点、跨平台聚合等可由公开数据验证； 实时营收、用户路径/漏斗、留存、LTV 等依赖内部埋点/经营数据，已下线或标注"需业务数据核验"（详见 数据与订阅说明）。
